# Nimzo Final Build Package

This package is the single GitHub-ready source package for Nimzo.

## Locked changes included in this package
- Numeric permanent Nimzo User ID; no nickname requirement.
- All-country selector during profile setup.
- English + Arabic only, with Arabic RTL-ready architecture.
- Date of birth and gender fields.
- Phone gallery/camera profile and cover upload to Supabase Storage; no URL entry.
- Premium/professional profile edit screen.
- Admin/activity profile tags.
- Wealth, Charm and Active levels.
- Followers, Following and Visitors.
- CP/Couple section foundation.
- Models section foundation for the future model system.
- Room lifetime gifting counter that never resets.
- Moment Like, Comment, Gift and Share actions.
- Moment gifting is server-authoritative and gives the receiver 45% diamonds; no room-owner 5% reward on Moment gifts.
- Moment lifetime gift total never resets.
- Duplicate image_picker dependency removed.
- Locked backend migration: `0005_locked_profile_lifetime_moment_gifts.sql`.

## Existing locked economy
100,000 room-gift coins sent = 45,000 receiver diamonds + 5,000 room-owner coins.
1 diamond = 1 coin for the internal exchange.
No cash withdrawal/cash-out hierarchy.
