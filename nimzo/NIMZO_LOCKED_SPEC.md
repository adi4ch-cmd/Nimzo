# Nimzo — Locked Product Specification

## Account / Profile
- No nickname/display-name requirement.
- Permanent numeric Nimzo ID generated by the backend (e.g. 100001, 100003, 100067).
- Country selector contains all countries.
- Supported app languages: English and Arabic only; Arabic UI is RTL.
- Required profile setup data: country, language, date of birth, gender, profile picture.
- Profile picture/cover are selected from phone gallery or camera and uploaded directly to Supabase Storage. Users never paste image URLs.
- Professional/premium profile editing UI; no childish/cheap visual style.
- Admin/activity tags can include TOP 1, TOP 3, ADMIN, VIP/SVIP and event/activity tags. Users cannot self-assign protected tags.
- Separate levels: Wealth, Charm, Active.
- Social stats: Following, Followers, Visitors.
- Visitors record users who opened the profile.
- CP/Couple section appears below social stats.
- Models section appears below CP; model system is backend-ready for a future custom model program.

## Rooms
- Room lifetime gifting never resets.
- Every successful room gift adds its total coin value to `lifetime_gift_coins`.
- Weekly/monthly reset is not used for the lifetime counter.
- Example: 10k today + 500k tomorrow + 1m later = 1.51m lifetime gifting.

## Moments
- Moment actions: Like, Comment, Gift, Share.
- Users can send gifts directly to a Moment author.
- Moment gifts use the same gift catalog and server-authoritative wallet transaction.
- Moment gifts give the receiver 45% of sent coins as diamonds.
- The room-owner 5% reward does NOT apply to Moment gifts.
- Moment lifetime gift total is retained and never reset.

## Economy
- 100,000 coins sent in a room => 45,000 receiver diamonds + 5,000 room-owner coins.
- 1 diamond = 1 coin for the internal exchange.
- No cash withdrawal/cash-out system.
- No agency/BD/host salary/manager commission/weekly settlement hierarchy.
