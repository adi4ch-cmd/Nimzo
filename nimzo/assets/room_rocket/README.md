# NIMZO Room Rocket: matching six-level Haza 4.9.0 set

All six launch videos and all six reward videos come from the same Haza set
provided by the owner. Other APK Rocket visuals are archived outside the app
bundle; the active player never mixes them into these six levels.

Each level plays its actual launch followed by its matching reward VAP clip.
Native VAP playback composites the encoded alpha mask. Silent clips receive
NIMZO sound effects; rewards 4–6 retain their embedded AAC soundtrack.

Server progress counts settled room gift coins at 5M, 10M, 20M, 30M, 50M and
100M, resets at 23:00 Asia/Riyadh, and deduplicates milestone events. Room
history, countdown and ranking read actual server records. The celebration
itself grants no coins or items; wallet economics are unchanged.

Original MP4 hashes are checked by tools/verify_room_rocket_media.py.
Device VAP, sound and voice coexistence require the Android runtime check.
